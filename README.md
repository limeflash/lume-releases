<h1 align="center">Lume</h1>

<p align="center">Лёгкий Discord-клиент со своим интерфейсом.<br>Голос, стримы и звонки работают на движке самого Discord.</p>

<p align="center"><a href="https://github.com/limeflash/lume-releases/releases/latest"><b>Скачать последнюю версию →</b></a></p>

---

Здесь публикуются только готовые сборки, исходный код в отдельном репозитории. Установленный Lume
проверяет этот репозиторий при запуске и обновляется сам.

## Какой файл скачать

| Система | Файл |
|---|---|
| Windows 10/11 x64 | `Lume_<версия>_x64-setup.exe` |
| Windows на ARM | `Lume_<версия>_arm64-setup.exe` |
| macOS, Apple Silicon (M1 и новее) | `Lume_<версия>_aarch64.dmg` |
| macOS, Intel | `Lume_<версия>_x64.dmg` |
| Linux | `.AppImage` (обновляется сам), `.deb` или `.rpm` |

**Windows** — основная платформа, работает всё. **macOS и Linux** пока экспериментальные:
- показ экрана идёт через системное окно выбора;
- нет глобальных хоткеев и игрового оверлея;
- голос на Linux зависит от WebRTC в системном WebKitGTK.

## Установка

- **Windows:** запустите установщик. Он не подписан, поэтому SmartScreen попросит подтверждения: «Подробнее» → «Выполнить в любом случае».
- **macOS:** перетащите Lume в «Программы» и один раз выполните в терминале `xattr -cr /Applications/Lume.app` (приложение не подписано).
- **Linux:** `chmod +x Lume_*.AppImage` и запуск, или установите `.deb` или `.rpm`.

Вход в аккаунт выполняется на странице Discord внутри Lume. Сессия хранится только на этом компьютере.
